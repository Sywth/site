# Sywth's Site

Progressive path tracer written in TypeScript and GLSL using WebGL2 on HTML canvas, with [cosine weighted sampling](https://en.wikipedia.org/wiki/Path_tracing#Algorithm), [good random sampling](https://en.wikipedia.org/wiki/Permuted_congruential_generator) and faked [ambient occlusion](https://en.wikipedia.org/wiki/Ambient_occlusion).
